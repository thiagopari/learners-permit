# Agent workspace

The OpenClaw workspace of Hyperion's agent, copied from the NemoClaw sandbox `navfix`
(`/sandbox/.openclaw/workspace`) on 2026-10-03.

- `AGENTS.md`: standing orders and operating rules
- `POLICY.md`, `SOUL.md`, `IDENTITY.md`: escalation policy, persona and identity
- `HEARTBEAT.md`: what the agent checks on each heartbeat
- `skills/warehouse-supervisor/SKILL.md`: the tools and rules for supervising the warehouse

`TOOLS.md` and `USER.md` are OpenClaw's default templates. The agent's runtime memory notes and the
sandbox's `openclaw.json` (which holds tokens) were left out on purpose.
