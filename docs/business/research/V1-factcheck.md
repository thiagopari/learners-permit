# V1 fact-check: pitch-slide numbers

Checked 2026-10-03 by opening each source again myself.
Method: BLS numbers came from the official BLS Public Data API v1, the QCEW open-data CSV and the data.bls.gov series viewer. The www.bls.gov HTML tables return HTTP 403 to automated fetches. The Siemens and AHA PDFs were downloaded and converted to text with pdftotext. SEC EDGAR blocked plain curl ("undeclared automated tool"), so I read the 10-K with WebFetch. For every web page, I read it with WebFetch and also downloaded the raw HTML and searched it for the exact strings.

- 8 confirmed as stated: #1, 2, 3, 4, 5, 6, 7, 10. #2 should be labelled "private, preliminary".
- 1 confirmed as a secondary estimate: #11. Label it as Sacra's estimate.
- 3 need a fix:

  - #9 Siemens: cite p.11; the sentence says "five years ago" (the baseline is 2019).

- None unverifiable.
